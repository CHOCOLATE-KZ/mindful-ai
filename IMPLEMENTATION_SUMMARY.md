## 💡 Примеры использования

### Добавить заметку в код
```javascript
// В компоненте
const handleAddNote = async () => {
  const { data, error } = await supabase
    .from('notes')
    .insert({
      user_id: user.id,
      mood: 7,
      sleep: 480,
      comment: 'Отличный день!'
    });
};
```

### Использовать аналитику
```javascript
import { useNotesAnalytics } from '@/app/(app)/notes/_hooks/useNotesAnalytics';

function MyComponent({ notes }) {
  const {
    avgMood,
    avgSleep,
    emotionalInsights,
    aiAnalysisPayload
  } = useNotesAnalytics(notes);

  return <div>{avgMood}/10 настроения</div>;
}
```

### Отправить на ИИ
```javascript
const response = await fetch('/api/notes/analyze', {
  method: 'POST',
  body: JSON.stringify({
    comments: notes.filter(n => n.comment),
    mood: avgMood,
    sleep: avgSleep
  })
});
```
