## 🐛 ПРОБЛЕМА КОТОРУЮ БЫЛО НУЖНО ИСПРАВИТЬ

### Предыдущий баг:
❌ AI отвечал: "Да, я смотрю на ваши записей в дневнике..."

### Почему это был баг:
- Нарушало PRIVACY обещание в system prompt
- Пользователь не понимает что модель не сохраняет данные
- System prompt говорит: "do not claim to store, remember, or access data"

### Текущее решение: ✅ ИСПРАВЛЕНО
- Функция `buildUserContext()` passes только МЕТАДАННЫЕ, не содержание
- System prompt ясно границы указывает
- Контекст отправляется как: "User Context: Имя: [name]. Язык: [language]..."
