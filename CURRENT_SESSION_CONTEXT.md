# SESSION CONTEXT: MindfulAI Psychology Assistant Development

## 📋 Что мы делаем

Разрабатываем **MindfulAI** - ассистента по психологии на основе Qwen2.5-7B для поддержки людей с эмоциональными трудностями. Главная цель - не просто теплый тон, а **структурированное применение психологических методик**.

## 🎯 Последние улучшения (Февраль 2026)

### ✅ Выполнено в этой сессии:

1. **Оптимизация базы знаний** 
   - Сжали психологическую базу с ~4600 до ~1200 токенов (74% редукция)
   - Все описания конвертированы в компактный формат пуль-пойнтов
   - **Качество не упало** - модель уже знает психологию, контекст это просто направление

2. **Добавлена специальная框架 для депрессии/низкой мотивации**
   - File: `src/app/api/chat/route.js` → `SYSTEM_PROMPT`
   - Добавлен раздел "SPECIAL FRAMEWORK FOR LOW MOTIVATION/DEPRESSION"
   - 5-шаговая схема:
     1. Validate (валидация эмоций)
     2. Name it (назвать поведенческую инертность)
     3. Micro-steps (микрошаги по 5 минут)
     4. Explain (объяснить почему это работает)
     5. Invite action (пригласить действовать СЕЙЧАС)

3. **Улучшена детекция депрессии**
   - File: `src/data/psychologyKnowledge.js` → `getRelevantKnowledge()`
   - Добавлены ключевые слова для апатии:
     - 'не могу заставить'
     - 'не хочется'
     - 'нет энергии'
   - Теперь система правильно распознает низкую мотивацию

4. **Конфигурация LM Studio**
   - Model: `qwen2.5-7b-instruct-uncensored`
   - Параметры: temp=0.7, max_tokens=512
   - Преимущества: хорошо понимает русский, эмпатичен, не цензурирован (можно обсуждать МЗ)

## 💡 Архитектурное понимание

**Важный момент**: Qwen2.5 уже знает психологию из тренировки. 
- Мы не "учим" модель 
- Мы "направляем" ее через контекст и промт
- `psychologyKnowledge.js` это **reminder + направление**, не обучение

Поэтому сжатие на 74% не влияет на качество - модель уже все знает.

Когда будешь защищать - упомяни:
1. **RAG-подход** - контекст умно выбирается по ключевым словам
