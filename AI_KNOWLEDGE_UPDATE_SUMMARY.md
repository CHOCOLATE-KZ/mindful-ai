## 🚀 Как это использовать

### Вариант 1: Прямо сейчас (уже работает!)

1. Убедитесь что LM Studio запущен:
   ```bash
   # Проверка
   curl http://localhost:1234/v1/models
   ```

2. Запустите проект:
   ```bash
   npm run dev
   ```

3. Тестируйте в чате:
   - "Мне тревожно" → AI использует техники для тревоги
   - "Мне грустно" → AI применяет подходы для депрессии
   - "Злюсь на всех" → AI предлагает работу с гневом

### Вариант 2: Добавить свои материалы

**Способ A - Через код:**
1. Откройте `src/data/psychologyKnowledge.js`
2. Добавьте новый раздел:
   ```javascript
   emotionRegulation: {
     // существующие...
     yourNewTopic: `Ваш контент здесь...`,
   }
   ```
3. Обновите ключевые слова в `getRelevantKnowledge()`

**Способ B - Из текстового файла:**
1. Используйте `docs/PSYCHOLOGY_KNOWLEDGE_BASE.txt` как шаблон
2. Копируйте нужные разделы
3. Адаптируйте под ваши нужды

## 🔧 Настройка под себя

### Изменить количество истории:

### Изменить параметры генерации:

## 📞 Troubleshooting

### "Psychology context not working"
→ Проверьте импорт в файлах:
```javascript
import { getRelevantKnowledge } from "@/data/psychologyKnowledge";
```

### "AI ignores the context"
→ Проверьте размер контекста (может быть слишком большой)
→ Используйте более сильную модель
→ Добавьте debug логирование

### "Russian language issues"
→ В SYSTEM_PROMPT добавлено правило о языке
→ Убедитесь что модель поддерживает русский (Qwen2.5 отлично)
