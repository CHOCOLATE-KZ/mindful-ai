### 4. **src/app/api/notes/analyze/route.js** (60 строк)
**Статус:** ✅ Новый файл создан

**Назначение:** REST API endpoint для подготовки анализа

**HTTP:**
```
POST /api/notes/analyze
Content-Type: application/json

Request:
{
  "comments": [
    {
      "date": "2024-01-28",
      "text": "Комментарий",
      "mood": 7,
      "sleep": 480
    }
  ],
  "mood": 7.5,
  "sleep": 450
}

Response:
{
  "success": true,
  "analysisId": "uuid",
  "prompt": "Структурированный запрос для ИИ",
  "commentsCount": 10,
  "timestamp": "2024-01-28T10:30:00Z"
}
```

**Функционал:**
- Валидация user_id
- Подготовка структурированного запроса для ИИ
- Сохранение истории анализа в БД
- Обработка ошибок
