```
│   └── Подготовка (aiAnalysisPayload)
│
└── Библиотеки
    └── Recharts (графики)

Backend (Next.js API)
└── API Routes
    └── /api/notes/analyze (POST)
        ├── Валидация
        ├── Подготовка prompt
        ├── Сохранение в БД
        └── Возврат результата

Database (Supabase PostgreSQL)
├── notes (основные)
├── notes_analysis (история)
├── notes_analysis_results (результаты)
└── ai_recommendations (рекомендации)
```
