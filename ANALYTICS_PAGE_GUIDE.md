# 📊 ANALYTICS PAGE - Аналитика тестов

**Статус:** ✅ Готова
**Путь:** `/analytics`
**Тип:** Client Component

---

## 🎯 Функциональность

### 1. Отображение результатов тестов
- ✅ Получает все результаты `tests_log` текущего пользователя
- ✅ Группирует по `test_key`
- ✅ Показывает количество попыток для каждого теста

### 2. Выбор теста для анализа
- ✅ Красивые кнопки выбора теста
- ✅ Показывает количество попыток для каждого
- ✅ Активный тест выделяется цветом

### 3. Статистика по выбранному тесту
- **Всего попыток** — общее количество прохождений
- **Последняя попытка** — дата и время последнего прохождения
- **Название теста** — полное название выбранного теста

### 4. Графики и диаграммы

#### 📈 Активность по дням (LineChart)
- X: даты
- Y: количество попыток в день
- Позволяет увидеть паттерны занятости

#### 🎯 Выбранные ответы топ-10 (BarChart)
- Самые популярные ответы на вопросы
- Показывает какие варианты выбирают чаще всего

#### 📊 Распределение ответов (PieChart)
- Круговая диаграмма всех выбранных ответов
- Цветовое разделение по вариантам

### 5. История всех попыток
- Список всех попыток с датами
- Показывает ответы каждой попытки
- Пронумерованы от новых к старым

## 🔌 Интеграция с Supabase

### Таблица: `tests_log`
```sql
SELECT id, test_key, answers, created_at 
FROM tests_log 
WHERE user_id = $1 
ORDER BY created_at DESC
```

### Структура ответов (JSONB)
```javascript
{
  "0": "Да",
  "1": "Иногда",
  "2": "Баланс"
}
```

## 🎨 Компоненты

### Состояния:
1. **Loading** — загрузка данных
2. **Not Authenticated** — требуется вход
3. **No Results** — нет результатов тестов, кнопка "Пройти первый тест"
4. **Analytics** — полная аналитика с графиками

## 🚀 Использование

### Открыть страницу:
```
http://localhost:3000/analytics
```

### Если нет результатов:
```
Показывается сообщение с ссылкой на /exercises
```

### Для просмотра графиков:
```
1. Выберите тест из списка
2. Графики автоматически обновятся
3. Прокрутите вниз для просмотра истории
```

```javascript
// dailyChart
[
  { date: "28.01.2024", attempts: 1 },
```

## 🐛 Отладка

### Проверить в консоли:
```javascript
// Проверить что данные загружаются
console.log("testResults:", testResults);

// Проверить выбранный тест
console.log("selectedTest:", selectedTest);

// Проверить аналитику
console.log("testAnalytics:", testAnalytics);
```

### Распространённые проблемы:

**Проблема:** Графики не показываются
**Решение:** Убедитесь что выбран тест (selectedTest !== null)

**Проблема:** "Требуется вход"
**Решение:** Авторизуйтесь в приложении

**Проблема:** Нет результатов
**Решение:** Пройдите минимум один тест на странице `/exercises`
