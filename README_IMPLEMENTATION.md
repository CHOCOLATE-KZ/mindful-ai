## 🔧 Архитектура

### React компоненты
```
pages/notes/
├── page.js                    [338 строк]
│   ├── useEffect (загрузка)
│   ├── saveNote (CRUD)
│   ├── removeNote (удаление)
│   ├── addQuickNote (мини)
│   └── render (UI)
│
├── _components/
│   └── NotesAIAnalysis.jsx    [80 строк]
│       ├── handleAnalyze
│       └── render (UI)
│
└── _hooks/
    └── useNotesAnalytics.js   [150 строк]
        ├── fullNotes (фильтр)
        ├── quickNotes (фильтр)
        ├── avgMood (расчет)
        ├── avgSleep (расчет)
        ├── emotionalInsights (анализ)
        └── aiAnalysisPayload (подготовка)
```

### API endpoints
```
/api/notes/analyze [POST]
├── Валидация user
├── Подготовка prompt
├── Сохранение истории
└── Возврат analysisId
```

### База данных
```
notes (основные заметки)
├── id, user_id, date
├── mood (1-10), sleep (минуты)
└── comment (текст)

notes_analysis (история анализов)
├── id, user_id, prompt
└── analyzed_at

notes_analysis_results (результаты ИИ)
├── analysis_id, ai_response
└── created_at

ai_recommendations (рекомендации)
├── user_id, content
└── created_at
```
