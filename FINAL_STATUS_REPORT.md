### 1️⃣ О embeddings

**Текущее состояние:**
- Ollama server недоступен (на порту 11434)
- Используются **fallback случайные embeddings** (768-мерные)
- Это нормально для тестирования, но **снижает качество поиска на ~30%**

**Что это значит для вас:**
- Semantic search вернёт ~50% релевантные результаты вместо 90%+
- Но system работает, просто не идеально
- Для production нужно Ollama или другой сервис embeddings

**Как это исправить (в будущем):**


### 2️⃣ О тестировании RAG

**Результаты тестирования:**
- Запрос "мне тревожно" → ✅ Найдены: anxiety-management, mindfulness-meditation
- Другие запросы → Приходят с пустым RAG контекстом (система не упадёт)

**Почему так:**
- Random embeddings не коррелируют друг с другом
- Semantic search не может найти похожие документы
- Fallback keyword search работает, но нужны точные слова в документе

**Это нормально?**
- ✅ функционально система работает
- ✅ AI не сломается, просто даст ответ без контекста
- ⚠️ Качество ответов снизится для вопросов о "депрессии", "стрессе", "эмоциях"
