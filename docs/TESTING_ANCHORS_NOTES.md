# 🧪 Тестирование якорей и заметок в чате

## Подготовка

### 1. Миграция БД (один раз)
Выполни SQL в Supabase:
```
Projects → Your Project → SQL Editor → New Query
```
Вставь SQL для создания `chat_notes` (таблица, индексы, RLS) и запусти.

### 2. Убедись, что локально всё работает
```bash
npm run dev
# Открой http://localhost:3000/chat
```

## Тестовые сценарии

### ✅ Сценарий 1: Якоря с жирным текстом в ответе
1. Напиши вопрос: `"Как мне лучше спать?"`
2. ИИ должен ответить с **жирными** якорями типа `**Режим сна**`
3. Проверь:
   - [ ] Якоря появились в левой панели
   - [ ] Якоря читаемые (не парсинг кода)
   - [ ] Они красивые (blue 50/80 background)

### ✅ Сценарий 2: Якоря извлечены из текста
1. Напиши вопрос: `"Чувствую себя перегруженным"`
2. ИИ ответит без жирного текста
3. Проверь:
   - [ ] Якоря автоматически извлечены (первые 3 предложения)
   - [ ] Они логичные (без `<` и `[`)
   - [ ] Максимум 5 слов в якоре

### ✅ Сценарий 3: Сохранение якорей в заметки
1. В левой панели → якорь → кнопка `✓`
2. Проверь:
   - [ ] Кнопка изменяется на `…` (loading)
   - [ ] Якорь появляется в "📝 Заметки"
   - [ ] Счётчик заметок обновился (+1)
   - [ ] Запись сохранилась в таблице `chat_notes`

### ✅ Сценарий 4: Обсуждение якоря
1. Кликни на любой якорь в панели
2. Проверь:
   - [ ] Текст появился в поле ввода: `"Хочу обсудить: [якорь]"`
   - [ ] Можешь добавить свой текст или отправить как есть
3. Отправь сообщение
4. Проверь:
   - [ ] ИИ ответил по теме якоря

### ✅ Сценарий 5: Повторное открытие чата
1. Закрой вкладку или обнови страницу (F5)
2. Вернись в чат
3. Проверь:
   - [ ] "📝 Заметки" загрузилась заново
   - [ ] Все сохраненные якоря присутствуют
   - [ ] История чата загрузилась

### ✅ Сценарий 6: Мобильный вид (или уменьшенный экран)
1. Открой F12 → Device Toolbar (lg < 1024px)
2. Проверь:
   - [ ] Левая панель скрыта (`hidden lg:block`)
   - [ ] Чат занимает всю ширину
   - [ ] Якоря всё ещё видны в сообщениях ИИ (карточки под текстом)

## Проверка консоли браузера

Открой DevTools (F12) → Console и проверь:

```javascript
// Должны быть сохраняемые якоря:
// POST /api/chat/notes ✓ 200 OK

// Должна загружаться история заметок:
// GET /api/chat/notes ✓ 200 OK

// Тест: посмотри на сохраненные якоря
fetch('/api/chat/notes', { credentials: 'include' })
  .then(r => r.json())
  .then(d => console.log('Заметки:', d.items))
```

## Проверка БД в Supabase

1. Projects → Your Project → SQL Editor
2. Выполни:
```sql
-- Проверь таблицу
SELECT * FROM chat_notes LIMIT 5;

-- Проверь RLS (должны быть 3 политики)
SELECT policyname FROM pg_policies WHERE tablename = 'chat_notes';

-- Проверь индекс
SELECT indexname FROM pg_indexes WHERE tablename = 'chat_notes';
```

## Частые проблемы

### 🔴 Якоря выглядят как парсинг кода (`<[channel]>...`)
**Решение**: Проверь, что ИИ генерирует якоря с `**текст**` или текст достаточно короткий

### 🔴 Заметки не сохраняются
**Решение**: 
1. Проверь в DevTools → Network → POST /api/chat/notes
2. Проверь консоль на ошибки
3. Убедись, что миграция БД выполнена

### 🔴 Левая панель не видна
**Решение**: Проверь, что экран достаточно широкий (≥lg, 1024px)

### 🔴 Якоря не загружаются при загрузке страницы
**Решение**: Проверь в Network, что GET /api/chat/notes работает (200 OK)

## Что результат должен быть

✅ **Хорошо**:
- Якоря: "Хронический стресс", "Нарушение сна", "Как справиться"
- Панель: красивая, sticky, с градиентом
- Заметки: список с датой и кликом для обсуждения
- Мобильно: панель скрыта, чат на всю ширину

❌ **Плохо**:
- Якоря: `<[channel]> commentary to=developer`
- Панель: серая, скучная, без интерактива
- Заметки: не загружаются или не сохраняются
