# 📋 Инструкция по обновлению трекера заметок

## ✅ Что добавлено:

### 1. Новые поля в БД
- **energy** (1-10) - уровень энергии
- **stress** (1-10) - уровень стресса
- **nutrition** (great/fine/ok/poor) - питание
- **exercise** (great/fine/ok/poor) - физическая активность
- **hobbies** (great/fine/ok/poor) - хобби/развлечения
- **social** (great/fine/ok/poor) - общение

### 2. UI улучшения
- ✨ Expandable секция "Дополнительные параметры"
- 📊 Недельный трекер в табличном виде (как на картинке)
- 🎯 Визуальные индикаторы активностей в истории
- 🎨 Улучшенные карточки с градиентами и анимациями

### 3. Функционал для ИИ
- Все новые данные передаются в `prepareNotesForAIAnalysis()`
- ИИ может анализировать корреляции между активностями и настроением
- Больше данных для персонализированных рекомендаций

---

## 🚀 Как запустить:

### Шаг 1: Обновить БД
Запустите миграцию в Supabase SQL Editor:
```bash
sql/notes_add_activities.sql
```

### Шаг 2: Проверить RLS политики
Убедитесь, что RLS политики разрешают чтение/запись новых полей.

### Шаг 3: Запустить приложение
```bash
npm run dev
```

---

## 📝 Как использовать:

1. **Базовая запись** - настроение, сон, комментарий (как раньше)
2. **Расширенная запись** - нажмите "Дополнительные параметры" и заполните энергию, стресс и активности
3. **Недельный обзор** - автоматически отображается внизу страницы

## 🎯 Преимущества для пользователя:

✅ Видит полную картину своего состояния  
✅ Недельный трекер показывает прогресс визуально  
✅ ИИ получает больше данных для лучших рекомендаций

## 🤖 Для разработчиков:

### Структура данных:
```javascript
{
  id: bigint,
  user_id: uuid,
  date: date,
  // Основные (как раньше)
  mood: integer (1-10),
  sleep: integer (минуты),
  comment: text,
  // Новые
  energy: integer (1-10),
  stress: integer (1-10),
  nutrition: 'great' | 'fine' | 'ok' | 'poor',
  exercise: 'great' | 'fine' | 'ok' | 'poor',
  hobbies: 'great' | 'fine' | 'ok' | 'poor',
  social: 'great' | 'fine' | 'ok' | 'poor'
}
```

### ИИ анализ:
```javascript
const data = prepareNotesForAIAnalysis(notes);
// data.allComments теперь содержит все новые поля
```
