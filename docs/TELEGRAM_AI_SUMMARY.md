# Telegram AI Integration - Summary

## Что было добавлено

### 1. ✅ LM Studio Client (`src/lib/lmStudioClient.js`)

Универсальный клиент для работы с LM Studio API:

- **callLmStudio()** - базовый вызов API
- **askAI()** - простой вопрос-ответ
- **askAIWithHistory()** - диалог с историей (последние 10 сообщений)
- **buildUserContext()** - получение контекста пользователя из БД

**Особенности:**
- Поддержка истории диалога
- Персонализация на основе данных пользователя
- System prompt для эмпатичного AI-ассистента
- Обработка ошибок LM Studio

### 2. ✅ AI Integration в Telegram Bot

**Обновлен `src/lib/telegram/handlers.js`:**
- `handleMessage()` теперь использует LM Studio для ответов
- Загружает историю диалога (последние 10 сообщений)
- Строит контекст пользователя
- Сохраняет переписку в `ai_messages` с `source: 'telegram'`
- Показывает "typing..." пока генерируется ответ
- Обработка ошибок (LM Studio недоступен, аккаунт не связан)

**Обновлен `handleHelp()`:**
- Добавлено описание AI-ассистента
- Объяснение как общаться с ботом

### 3. ✅ Database Migration

**Добавлены SQL-изменения для `ai_messages`:**
- Добавлена колонка `source` (TEXT) для различения web/telegram
- Индекс для быстрого поиска по источнику
- Дефолтное значение 'web' для существующих записей

**Обновлен `src/app/api/chat/route.js`:**
- Добавлено `source: 'web'` при сохранении сообщений с сайта
- Теперь история разделена между web и telegram

## Как это работает

### Поток данных

```
Пользователь → Telegram Bot
              ↓
       getUserIdByTelegramId()
              ↓
       Проверка связки аккаунта
              ↓
       Получить историю (10 msg)
              ↓
       buildUserContext()
              ↓
       askAIWithHistory()
              ↓
       LM Studio API
              ↓
       Сохранить в ai_messages
              ↓
       Ответ пользователю
```

### Контекст пользователя

AI получает:
- Имя пользователя
- Язык интерфейса
- Последняя заметка (дата, настроение, сон)
- История диалога (последние 10 сообщений)

### System Prompt

```
Ты эмпатичный психологический ассистент. 
Отвечай коротко, тепло, без клише.
Давай простые практические шаги (дыхание, сон, движение, дневник).
Избегай диагнозов и директив.
Если нужен специалист — мягко предложи обратиться.
```

## Что нужно сделать

### 1. Выполнить миграцию БД

```sql
-- В Supabase SQL Editor
ALTER TABLE ai_messages
ADD COLUMN IF NOT EXISTS source TEXT DEFAULT 'web';

CREATE INDEX IF NOT EXISTS idx_ai_messages_source 
ON ai_messages(user_id, source, created_at DESC);

UPDATE ai_messages SET source = 'web' WHERE source IS NULL;
```

### 2. Убедиться что LM Studio запущен

- URL: http://127.0.0.1:1234
- Модель: openai/gpt-oss-20b
- Проверка: `curl http://127.0.0.1:1234/v1/models`

### 3. Проверить .env.local

```env
LMSTUDIO_BASE_URL=http://127.0.0.1:1234
LMSTUDIO_MODEL=openai/gpt-oss-20b
TELEGRAM_BOT_TOKEN=8328292703:AAFuYaEE_WeuDQwKa0zp2NTg79CihCjqID0
TELEGRAM_BOT_USERNAME=IITUpsychologyAIbot
```

### 4. Запустить бота

```bash
npm run telegram:poll
```

### 5. Протестировать

## Примеры диалогов

### Простой вопрос
```
User: Как справиться со стрессом?
Bot: Попробуйте технику "5-4-3-2-1": найдите вокруг 5 вещей, 
     которые видите, 4 — которые слышите, 3 — которые можете 
     потрогать, 2 запаха и 1 вкус. Это помогает вернуться в момент "здесь и сейчас".
```

### С контекстом пользователя
```
User: Не могу уснуть
Bot: Вижу, что ваш последний сон составил 4 часа. 
     Попробуйте сегодня:
     1. Отключить экраны за час до сна
     2. Прогуляться 10-15 минут
     3. Послушать спокойную музыку
     
     Если проблема сохраняется несколько дней — 
     стоит обратиться к специалисту.
```

### Продолжение диалога
```
User: Я чувствую тревогу
Bot: Понимаю вас. Попробуйте дыхательную практику: 
     вдох на 4 счёта, задержка на 4, выдох на 4, пауза на 4.
     Несколько циклов помогут успокоиться.

User: А что еще можно?
Bot: Также помогут:
     • Записать мысли в дневник
     • Короткая прогулка
     • Позвонить близкому человеку
     
     Что из этого вам ближе?
```
