## 🚀 Быстрый старт (30 сек)

1. **Обновите три файла:**
   - `page.js` — добавьте `async` и `await props.params`
   - `TestRunner.jsx` — замените на новую версию (300+ строк)
   - `testsData.js` — создайте новый файл

2. **Создайте таблицу в Supabase:**
   ```sql
   CREATE TABLE tests_log (
     id BIGSERIAL PRIMARY KEY,
     user_id UUID NOT NULL REFERENCES auth.users(id),
     test_key VARCHAR(255) NOT NULL,
     answers JSONB NOT NULL,
     created_at TIMESTAMP DEFAULT now()
   );
   ```

3. **Запустите проект:**
   ```bash
   npm run dev
   ```

4. **Откройте тест:**
   http://localhost:3000/exercises/uncertainty_tolerance
